# Accessibility evidence

This is the execution record for the migration inventory. It is intentionally
unresolved until the required browser, assistive technology and physical-device
walks are performed. The rows below are the 55 WCAG 2.2 A/AA applicability
decisions required for each relevant route/state; `not-tested` is not a
conformance result.

Required environments are Safari + VoiceOver on macOS/iOS, Chrome + NVDA on
Windows, Chrome + TalkBack on Android, and the compiled applications at 320,
360, 768 and 1440 CSS pixels, plus 200% text and 400% browser zoom. Browser
emulation does not satisfy the physical camera/location rows. Fixtures must be
synthetic and must not contain credentials, invitation tokens or personal
evidence.

Each executed record must add: inventory surface ID, route, state, persona,
criterion, browser/OS/AT versions, viewport or zoom, fixture, steps, expected
and observed behavior, artifact, reviewer and execution date. `not-applicable`
requires a route/state-specific rationale. A skipped, blocked or untested row
remains unresolved and cannot be converted into a pass by an axe result.
