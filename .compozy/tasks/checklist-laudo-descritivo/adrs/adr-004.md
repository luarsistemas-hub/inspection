# ADR-004: Require an approved inventory baseline for new move-out inspections

## Status

Accepted

## Date

2026-11-03

## Context

The product has legacy comparisons based on media-only origins and a newer item-level comparison against an approved inventory. The user chose to prevent new move-out inspections without an approved baseline.

## Decision

A new move-out inspection can start only when an approved, compatible inventory baseline is selected and pinned. For a media-only legacy origin, the user must catalog and approve it first. Existing legacy inspections and reports remain readable, with their historical comparison behavior and versions preserved.

## Alternatives Considered

### Alternative 1: Continue creating media-only comparisons

- **Description**: Offer the legacy visual flow for new move-out work.
- **Pros**: Fewer prerequisites.
- **Cons**: Produces weaker, less explainable item-level conclusions.
- **Why rejected**: The user chose an approved baseline gate.

### Alternative 2: Hide legacy reports until migration

- **Description**: Require cataloging even to read historical documents.
- **Pros**: Uniform presentation.
- **Cons**: Breaks historical access and changes issued records.
- **Why rejected**: The user chose continued read access.

## Consequences

### Positive

- New comparison conclusions have a reviewed reference and fixed identity.

### Negative

- A media-only origin requires cataloging and approval before new move-out work.

### Risks

- Entry points may disagree about eligibility; all creation paths must enforce the same rule.

## Implementation Notes

An approved baseline does not itself prove every component was observed. Comparison must report “no basis to compare” or “not observed” where evidence is insufficient.
