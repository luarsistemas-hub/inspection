# ADR-009: Use automatic publication for the new report workflow

## Status

Accepted

## Date

2026-11-03

## Context

The tenant publication policy defaults to manual, while the user selected automatic issue for the new descriptive and comparison reports even with unreviewed observations or coverage gaps.

## Decision

For new schema-v3 descriptive and approved-baseline comparison reports, the classification/report event creates and publishes the immutable snapshot transactionally. Existing manual-policy behavior remains for historical/legacy workflows. The new workflow does not reinterpret tenant manual policy as an approval gate. Terminal AI failure or absent AI consent produces an explicit limited report once the capture inputs are reportable; pending media receipt/verification is not reportable.

## Alternatives Considered

### Alternative 1: Change the global default to automatic

- **Description**: Make all tenants and old report modes automatic.
- **Pros**: Simple default.
- **Cons**: Changes unrelated legacy workflows and configured expectations.
- **Why rejected**: The decision concerns this new workflow.

### Alternative 2: Honor manual policy for v3 reports

- **Description**: Require a manager click for some tenants.
- **Pros**: Preserves tenant preference.
- **Cons**: Conflicts with the chosen automatic product behavior.
- **Why rejected**: The user explicitly selected automatic publication.

## Consequences

### Positive

- A report exists promptly with the uncertainty it actually contains.

### Negative

- The existing manual policy needs clear Admin copy about its limited applicability.

### Risks

- Duplicate events could produce duplicate publications; reuse the snapshot lock and input digest for idempotence.

## Implementation Notes

The current invitation and submission flows require AI consent, so the no-consent report is out of scope (PRD D-1) and `NOT_AUTHORIZED` has no producer in this release. Do not auto-activate an inventory baseline. Keep PDF rendering retryable independently of snapshot/publication transaction success.
